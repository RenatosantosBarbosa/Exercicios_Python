# 🐍 Exercícios Python

Repositório criado para registrar minha evolução nos estudos de Python através de exercícios práticos.

Já havia estudado parte desses conteúdos anteriormente, mas depois de um período sem praticar, decidi retomar os fundamentos e refazer exercícios para revisar os conceitos, reforçar minha lógica de programação e recuperar a prática com a linguagem.

> **📌 Sobre este repositório:** os exercícios apresentados aqui fazem parte principalmente de uma etapa de revisão e consolidação dos fundamentos. Alguns conceitos e projetos mais avançados já foram estudados anteriormente, mas estou revisando a base antes de continuar avançando.

## 📚 Conteúdos revisados

- Variáveis e tipos de dados
- Entrada de dados com `input()`
- Conversão de tipos
- Operadores matemáticos e relacionais
- `if`, `elif` e `else`
- Operadores lógicos
- Validação de dados
- `match/case`
- Cálculos e conversões
- Estruturas de decisão
- Formatação de saída com f-strings

## 🎯 Objetivo

Utilizar exercícios práticos para revisar conhecimentos já estudados, fortalecer a lógica de programação e construir uma base mais sólida para continuar avançando em Python.

Acredito que revisar conteúdos já estudados também faz parte do aprendizado. Além de relembrar conceitos, a prática permite identificar detalhes que podem ter passado despercebidos anteriormente e melhorar a forma de resolver problemas.

## 🚀 Próximos passos
